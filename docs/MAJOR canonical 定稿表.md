# MAJOR canonical 定稿表

## 文档定位

- **适用范围**：仅覆盖本轮标准化改造纳入范围的 `MAJOR` 域。
- **源码基线**：`apps/api/src/modules/jobs/jobs-normalization.seed-data.ts`。
- **版本口径**：2026-04-29 正式定稿口径；后续若 seed 变更，应重新生成本表并同步评审。

## 定稿原则

- **短 canonical 优先**：主词仅保留平台稳定使用的大类专业词。
- **长全称下沉 alias**：学院全称、专业全称、旧长 canonical 统一下沉为 alias。
- **专业大类收口**：如 `计算机 / 财务 / 机械` 等大类作为主词，不再把细分全称提升为 canonical。
- **组合类可治理**：`材料化工`、`土木建筑`、`物流供应链` 等组合 canonical 继续保留，便于运营维护与回填。
