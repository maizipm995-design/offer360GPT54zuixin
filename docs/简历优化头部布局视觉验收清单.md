# 简历优化头部布局视觉验收清单

适用页面：`/resume-optimizer`

适用样式：`商务 / 突出 / 清晰 / 基础 / 正式 / 工作`

适用状态：`无头像 / 有头像 / 有校徽 / 头像+校徽`

## 验收目标

- 验证六套头部布局在不同资源状态下的排版稳定性。
- 验证“外层容器位置切换”和“内层基础信息排版”已完全解耦。
- 验证头像、基础信息、校徽三者的联动关系符合既定规范。

## 统一前提

- 基础信息容器包含：`姓名 / 电话 / 邮箱 / 到岗时间 / 求职意向 / 现居城市 / 作品链接`
- 基础信息容器内部文字固定左对齐。
- 用户切换 `居左 / 居中 / 居右` 时，只允许改变头像容器与基础信息容器的相对位置。
- 校徽与头像必须错位显示，不允许出现重叠、遮挡、压边。
- 页面切换样式、切换对齐、上传或删除头像/校徽后，头部区域不应出现抖动、塌陷、超出页边距、容器高度突变。

## 对齐权限总表

- `基础`：允许 `居左 / 居中 / 居右`
- `突出`：允许 `居左 / 居右`，`居中` 禁用
- `清晰`：允许 `居左 / 居右`，`居中` 禁用
- `正式`：允许 `居左 / 居右`，`居中` 禁用
- `商务`：固定布局，`居左 / 居中 / 居右` 全部禁用
- `工作`：固定布局，`居左 / 居中 / 居右` 全部禁用

## 联动规则总表

- `基础`
- 基础信息 `居左`：头像在右侧
- 基础信息 `居右`：头像在左侧
- 基础信息 `居中`：头像固定在右侧

- `突出 / 清晰 / 正式`
- 基础信息 `居左`：头像在右侧
- 基础信息 `居右`：头像在左侧

- `商务 / 工作`
- 头像固定居中
- 基础信息固定在头像正下方

- 校徽联动
- 头像在左侧：校徽在右上角
- 头像在右侧或居中：校徽在左上角

## 通用检查项

- 样式切换后，对齐按钮的可点击状态是否符合权限规则。
- 对齐切换后，基础信息容器内部文字是否始终左对齐。
- 姓名是否始终独占头部信息首行，不与电话、邮箱等混排。
- 头像容器和基础信息容器是否为独立块级区域，不互相挤压。
- 校徽是否始终贴近页眉上缘，且与头像处于对侧。
- 无头像、无校徽时，头部是否仍保持完整留白和稳定结构。
- 有头像或校徽时，容器宽度是否重新分配合理，不出现文字被过度挤压。

## 验收步骤

1. 打开 `http://localhost:13000/resume-optimizer`
2. 进入头部布局配置区，依次切换六套头部样式
3. 对每套样式分别执行四组资源状态验证：
4. `无头像`
5. `有头像`
6. `有校徽`
7. `头像+校徽`
8. 对允许左右切换的样式，再分别验证 `居左 / 居右`
9. 对 `基础` 样式，额外验证 `居中`

## 六套样式逐项验收

### 1. 商务

- 按钮状态：`居左 / 居中 / 居右` 全部禁用
- 固定布局：头像居中，基础信息在头像下方
- 无头像：头像占位不塌陷，基础信息仍垂直居中且内部左对齐
- 有头像：头像居中，基础信息容器不左右偏移
- 有校徽：校徽显示在左上角，不压住头像
- 头像+校徽：头像居中、校徽左上，二者明显错位

### 2. 工作

- 按钮状态：`居左 / 居中 / 居右` 全部禁用
- 固定布局：头像居中，基础信息在头像下方
- 无头像：顶部背景造型仍完整，信息区不因头像缺失上移错位
- 有头像：头像居中，信息区与头像间距稳定
- 有校徽：校徽显示在左上角，不破坏顶部弧形背景
- 头像+校徽：头像居中、校徽左上，互不重叠

### 3. 基础

- 按钮状态：`居左 / 居中 / 居右` 均可点击
- 居左：基础信息容器在左，头像在右，基础信息内部左对齐
- 居中：基础信息容器整体居中，头像固定在右，基础信息内部左对齐
- 居右：基础信息容器在右，头像在左，基础信息内部仍保持左对齐，禁止出现整块文字右对齐
- 无头像：信息容器位置切换后仍保持稳定，页面不塌陷
- 有头像：头像与信息容器交换位置时不互相挤压
- 有校徽：当头像在右或居中时校徽在左上；当头像在左时校徽在右上
- 头像+校徽：头像与校徽分处两侧上角，信息容器位于中间区域

### 4. 突出

- 按钮状态：`居左 / 居右` 可点击，`居中` 禁用
- 居左：基础信息在左，头像在右，信息内部保持左对齐
- 居右：基础信息在右，头像在左，信息内部保持左对齐
- 无头像：渐变/色块头部仍完整，不因缺头像导致文字贴边
- 有头像：头像贴对侧边缘但不贴出安全区
- 有校徽：校徽始终在头像对侧的页眉上角
- 头像+校徽：白字区域、头像、校徽三者层级清晰，无覆盖

### 5. 清晰

- 按钮状态：`居左 / 居右` 可点击，`居中` 禁用
- 居左：基础信息在左，头像在右，信息内部保持左对齐
- 居右：基础信息在右，头像在左，信息内部保持左对齐
- 无头像：左/右切换后信息块宽度稳定
- 有头像：头像在对侧，信息块不出现整体右对齐
- 有校徽：校徽与头像自动错侧排布
- 头像+校徽：头像与校徽分别贴近左右页眉位置，不重叠

### 6. 正式

- 按钮状态：`居左 / 居右` 可点击，`居中` 禁用
- 居左：基础信息在左，头像在右，信息内部保持左对齐
- 居右：基础信息在右，头像在左，信息内部保持左对齐
- 无头像：顶部色条与信息容器对齐稳定
- 有头像：头像与顶部色条之间不发生裁切或贴边
- 有校徽：校徽位于头像对侧上角，且不压住顶部色条
- 头像+校徽：头像、校徽、信息容器三者层次稳定，页眉留白正常

## 必过判定

- 任何样式在 `居右` 状态下，基础信息容器内部都不得变成右对齐。
- 任何样式在 `头像+校徽` 状态下，都不得出现头像与校徽重叠。
- `商务 / 工作` 的三枚对齐按钮必须全部不可点击。
- `突出 / 清晰 / 正式` 的 `居中` 按钮必须不可点击。
- `基础` 样式的三档切换必须全部可用，且头像联动符合规则。

## 建议留档

- 每套样式至少保留 4 张截图：
- `无头像`
- `有头像`
- `有校徽`
- `头像+校徽`

- 若该样式支持对齐切换，建议追加：
- `居左`
- `居右`
- `基础` 样式额外加 `居中`
