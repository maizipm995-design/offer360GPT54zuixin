# JOB_TITLE canonical 定稿表

## 文档定位

- **适用范围**：仅覆盖本轮标准化改造纳入范围的 `JOB_TITLE` 域。
- **源码基线**：`apps/api/src/modules/jobs/jobs-normalization.seed-data.ts`。
- **版本口径**：2026-04-29 正式定稿口径；后续若 seed 变更，应重新生成本表并同步评审。

## 定稿原则

- **短 canonical 优先**：主词仅保留平台长期稳定使用的短词 / 大类词。
- **长词下沉 alias**：岗位细写法、历史长 canonical 统一下沉为 alias。
- **方向显式分开**：`开发` 与 `研发` 保持分离，`产品` 与 `运营` 保持分离。
- **尾部兜底可追踪**：`其他职位` 仅作为人工复核 fallback 使用，不再标记为 legacy bucket。
