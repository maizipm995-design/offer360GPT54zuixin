# 项目迭代总台账

## 一、文档目标

这份文档用于沉淀整个项目的**版本迭代总览**，帮助任何接手人快速回答四个问题：

1. 最近做了什么；
2. 当前已经完成到哪一步；
3. 后面还要跟进什么；
4. 是否存在遗留风险或未解决问题。

## 二、使用规则

- **功能开发、问题修复、优化调整完成后**，都应补一条记录；
- **优先使用命令留痕脚本同步台账**：
  - `npm run record:cmd -- --append-ledger --summary "..." --done "..." --followup "..." --issue "..." -- <command>`
- 如果本次工作主要是方案、文档、梳理类内容，也要手动补充一条简要记录；
- 每条记录保持简短，重点写清：**核心操作 / 已完成 / 待跟进 / 遗留问题 / 对应专项记录**。

## 四、字段说明

- **核心操作**：这次迭代最重要的一句话总结；
- **已完成**：已经真正交付或落地的事项；
- **待跟进**：下一步应该接着做什么；
- **遗留问题**：当前已知但尚未解决的风险或缺口；
- **专项记录**：对应的单次命令独立记录文档，便于追溯。
