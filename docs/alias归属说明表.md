# alias归属说明表

## 文档定位

- **适用范围**：本轮标准化改造重点域 `JOB_TITLE` 与 `MAJOR`。
- **目的**：为后台词典维护、导入导出审核、搜索/推荐回归提供统一 alias 归属说明。
- **源码基线**：`apps/api/src/modules/jobs/jobs-normalization.seed-data.ts`。

## 维护规则

- **exact**：仅用于查词归一，不进入搜索与推荐的文本扩召回。
- **contains**：除归一外，还会进入搜索与推荐文本召回，仅用于稳定长词。
- **新增 alias 前**：必须先确认是否已有 canonical 可挂载；禁止把长全称再提升回 canonical。
