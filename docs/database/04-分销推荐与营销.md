# 数据库表说明 - 分销推荐与营销

本分类负责处理 Offer360 平台的邀请返利、分销链路追踪、用户钱包余额管理及佣金分配逻辑。

## 1. 邀请短链重定向表 (inv_redirect_link)

- **核心用途**：生成并存储带有随机 Key 的邀请短链接，实现邀请人 ID 的隐秘传递。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 记录 ID | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 有 |
| randomKey | 链接随机码 | URL 中的唯一识别串 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| inviterUid | 邀请人 ID | 谁生成的这个邀请链接 | 必填 | 文本 | 否 | 关联 users.id | 否 | 有 |
| expireAt | 失效时间 | 该链接何时过有效期 | 选填 | 日期 | 否 | 无 | 否 | 有 |
| createAt | 生成时间 | 链接创建的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 2. 邀请访客追踪表 (inv_visitor_trace)

- **核心用途**：记录每一个通过邀请链接访问网站的原始访客信息（IP、设备等），用于防作弊。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 追踪记录 ID | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 无 |
| traceSn | 追踪唯一流水号| 生成的唯一追踪 ID | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 无 |
| inviterUid | 归属邀请人 | 这次访问算谁带过来的 | 必填 | 文本 | 否 | 关联 users.id | 否 | 无 |
| ip | 访客 IP | 访问者的网络 IP 地址 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| userAgent | 浏览器指纹 | 访客的设备/浏览器信息 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| clickAt | 点击时间 | 访问发生的精确时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| expireAt | 缓存失效时间 | 该追踪状态在系统中的保留期 | 必填 | 日期 | 否 | 无 | 否 | 无 |

---

## 3. 用户钱包表 (user_wallet)

- **核心用途**：存储分销员（邀请人）的余额、冻结资金及累计收益。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 钱包编号 | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 有 |
| userId | 所属用户 ID | 关联的用户 ID | 必填 | 文本 | 是 (唯一键) | 关联 users.id | 否 | 有 |
| availableBalance| 可用余额 | 已经结算、可随时提现的佣金 | 必填 | 数字(Decimal) | 否 | 无 | 是 (默认0) | 有 |
| frozenBalance | 冻结金额 | 订单支付后尚未结算的待处理佣金 | 必填 | 数字(Decimal) | 否 | 无 | 是 (默认0) | 0 |
| totalEarn | 累计总收益 | 历史以来在该平台赚取的全部佣金 | 必填 | 数字(Decimal) | 否 | 无 | 是 (默认0) | 有 |
| updateAt | 最近更新时间 | 余额变动的最后时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 4. 佣金流水日志表 (commission_log)

- **核心用途**：记录每一笔因分销产生的收益明细。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 流水 ID | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 无 |
| orderId | 触发订单 ID | 关联的服务订单 | 必填 | 文本 | 否 | 关联 service_orders.id | 否 | 无 |
| inviterUid | 获利者 ID | 谁收到了这笔佣金 | 必填 | 文本 | 否 | 关联 users.id (邀请人) | 否 | 无 |
| consumeUid | 消费者 ID | 谁下的单 (被邀请人) | 必填 | 文本 | 否 | 关联 users.id (消费者) | 否 | 无 |
| commissionRate | 返佣比例 | 下单时的实时返佣比例 (如 15) | 必填 | 数字 | 否 | 无 | 是 (默认15) | 无 |
| commissionMoney| 佣金金额 | 获利者实际分得的钱 | 必填 | 数字(Decimal) | 否 | 无 | 否 | 无 |
| originalConsumeMoney| 订单原价 | 参与分成计算的原始订单金额 | 必填 | 数字(Decimal) | 否 | 无 | 否 | 无 |
| logType | 日志类型 | 1(订单返利), 2(提现) 等 | 必填 | 数字 | 否 | 无 | 否 | 无 |
| createAt | 产生时间 | 该笔收益记录的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 5. 佣金全局配置表 (commission_config)

- **核心用途**：系统后台统一设置的默认分销比例。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 配置 ID | 固定为 1 的记录 | 必填 | 数字 | 是 | 无 | 是 | 1 |
| oneLevelRate | 一级返佣比例 | 默认给邀请人的返利百分比 | 必填 | 数字 | 否 | 无 | 是 (默认15) | 15 |
| updateAt | 更新时间 | 最近修改配置的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 6. 邀请绑定记录表 (inv_bind_log)

- **核心用途**：持久化记录“谁邀请了谁”的绑定动作，用于回溯分销关系建立的历史。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 绑定 ID | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 无 |
| inviterUid | 邀请人 ID | 发出邀请的用户 | 必填 | 文本 | 否 | 关联 users.id | 否 | 无 |
| newUserUid | 被邀请人 ID | 接受邀请的新用户 | 必填 | 文本 | 否 | 关联 users.id | 否 | 无 |
| bindTime | 绑定时间 | 关系正式确立的时间点 | 必填 | 日期 | 否 | 无 | 是 | 无 |
