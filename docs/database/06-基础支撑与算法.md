# 数据库表说明 - 基础支撑与算法

本分类包含支持全站运行的基础设施数据表，包括数据标准化（归一化）词典、行政区域层级，以及专属推荐功能的打分算法配置。

## 1. 数据归一化术语表 (normalization_terms)

- **核心用途**：存储全站标准化的专业词典，如标准的城市名、学校名、专业名及学历等级。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 术语内码 | UUID 字符串 | 必填 | 文本 | 是 | 关联别名/地名表 | 是 | 有 (大量初始化词典) |
| domain | 所属领域 | LOCATION, DEGREE, MAJOR 等 | 必填 | 下拉选项 | 否 | 无 | 否 | 有 |
| canonicalName | 标准名称 | 系统内部统一使用的名称 (如 南京) | 必填 | 文本 | 否 | 无 | 否 | 有 |
| canonicalCode | 标准编码 | 对应的外部标准码 (如 行政区划码) | 选填 | 文本 | 否 | 无 | 否 | 有 |
| level | 层级标识 | 城市级别、省份等 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| status | 启用状态 | active(启用), inactive(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| sortOrder | 排序序号 | 在下拉框或列表中的显示顺序 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 有 |
| metadata | 额外元数据 | 存储 JSON 格式的扩展信息 | 选填 | 文本(JSON) | 否 | 无 | 否 | 有 |
| createdAt | 创建时间 | 词条录入时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最近修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 2. 数据归一化别名表 (normalization_aliases)

- **核心用途**：存储术语的非标准称呼（别名），用于模糊匹配和同义词解析。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 别名编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| termId | 关联标准术语 | 属于哪一个标准词条 | 必填 | 文本 | 否 | 关联 terms.id | 否 | 有 |
| aliasName | 原始别名 | 用户填写的或爬虫抓取的原始词 (如 宁) | 必填 | 文本 | 否 | 无 | 否 | 有 |
| aliasNormalized| 归一化别名 | 经过大小写、空格处理后的查找键 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| matchMode | 匹配模式 | exact(精确), partial(部分) | 必填 | 下拉选项 | 否 | 无 | 是 (默认exact) | 有 |
| status | 启用状态 | active(启用), inactive(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| source | 来源标记 | seed(初始), user(用户输入) | 选填 | 文本 | 否 | 无 | 否 | 有 |
| sortOrder | 排序权重 | 匹配时的优先级排序 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 有 |

---

## 3. 行政区域层级表 (location_hierarchies)

- **核心用途**：定义城市与省份之间的所属关系，支持“只补父、不展子”的推荐逻辑。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 层级 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 (省市关联词典) |
| provinceTermId | 所属省份术语 | 关联省份的术语 ID | 必填 | 文本 | 否 | 关联 terms.id | 否 | 有 |
| cityTermId | 对应城市术语 | 关联城市的术语 ID | 必填 | 文本 | 是 (唯一键) | 关联 terms.id | 否 | 有 |
| status | 状态 | active(启用), inactive(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |

---

## 4. 专属推荐算法配置表 (jobs_recommendation_config)

- **核心用途**：存储运营端可调的岗位推荐打分权重，实现“动态千人千面”。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 配置 ID | 固定为 1 的记录 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 1 |
| companyWeight | 公司匹配权重 | 用户意向公司命中的加分 | 必填 | 数字 | 否 | 无 | 是 (默认35) | 35 |
| jobWeight | 岗位匹配权重 | 用户意向岗位命中的加分 | 必填 | 数字 | 否 | 无 | 是 (默认30) | 30 |
| cityExactWeight | 城市精确权重 | 城市完全一致时的加分 | 必填 | 数字 | 否 | 无 | 是 (默认20) | 20 |
| cityParentWeight| 城市上级权重 | 意向城市同省时的加分 | 必填 | 数字 | 否 | 无 | 是 (默认10) | 10 |
| degreeWeight | 学历权重 | 学历档位匹配时的加分 | 必填 | 数字 | 否 | 无 | 是 (默认8) | 8 |
| majorWeight | 专业权重 | 专业相关性匹配加分 | 必填 | 数字 | 否 | 无 | 是 (默认8) | 8 |
| fresh3DaysWeight| 3天内上新加分 | 极速上新岗位的时效加分 | 必填 | 数字 | 否 | 无 | 是 (默认6) | 6 |
| fresh7DaysWeight| 7天内上新加分 | 一周内上新岗位的时效加分 | 必填 | 数字 | 否 | 无 | 是 (默认3) | 3 |
| stateOwnedFallbackWeight| 央国企兜底分 | 默认对优质企业的权重偏移 | 必填 | 数字 | 否 | 无 | 是 (默认4) | 4 |
| deliveredPenalty| 已投递惩罚分 | 对已投递过的岗位进行降权，避免重复 | 必填 | 数字 | 否 | 无 | 是 (默认-12) | -12 |
| heatMax | 热度上限 | 单个岗位最高能拿到的热度分 | 必填 | 数字 | 否 | 无 | 是 (默认6) | 6 |
| hotAccessThreshold| 热门访问阈值 | 触发热度加分的点击量门槛 | 必填 | 数字 | 否 | 无 | 是 (默认50) | 50 |
| hotDeliveryThreshold| 热门投递阈值 | 触发热度加分的投递量门槛 | 必填 | 数字 | 否 | 无 | 是 (默认10) | 10 |
| updatedAt | 最近修改时间 | 配置最后调整的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
