# 数据库表说明 - 核心求职业务

本分类包含 Offer360 平台最核心的求职业务数据表，涵盖招聘岗位、用户信息、求职意向及进度追踪。

## 1. 招聘公告表 (job_announcements)

- **核心用途**：存储全站发布的招聘岗位公告信息，是 C 端用户浏览和投递的主要数据源。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 岗位唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 (演示岗位) |
| companyFullName | 企业全称 | 公司的完整名称 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| enterpriseNature | 企业性质 | 央企、国企、私企等 | 选填 | 下拉选项 | 否 | 无 | 否 | 有 |
| degreeRequirement | 学历要求 | 本科、硕士、博士等 | 选填 | 下拉选项 | 否 | 无 | 否 | 有 |
| workLocation | 工作地点 | 岗位所在的城市或地区 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| jobName | 岗位名称 | 具体职位的名称 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| jobCategory | 岗位类别 | 技术类、产品类、运营类等 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| recruitmentType | 招聘类型 | 校招、实习、社招等 | 选填 | 下拉选项 | 否 | 无 | 否 | 有 |
| deadlineAt | 截止日期 | 招聘截止的日期文本 | 选填 | 日期文本 | 否 | 无 | 否 | 有 |
| announcementUrl | 公告原文链接 | 原始招聘页面的 URL | 选填 | 文本 | 否 | 无 | 否 | 有 |
| deliveryUrl | 投递入口链接 | 投递简历的 URL 或邮箱 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| graduationSession | 面向届别 | 2026届、2027届等 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| referralCode | 内推码 | 该岗位的专属内推码 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| announcementTitle | 公告标题 | 前台展示的简练标题 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| industry | 行业领域 | 互联网、金融、制造业等 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| entryDate | 录入日期 | 岗位进入系统的日期 | 选填 | 日期文本 | 否 | 无 | 否 | 有 |
| accessClickCount | 累计访问量 | 岗位被查看的总次数 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 0 |
| deliveryMarkCount | 投递标记量 | 用户标记已投递的总次数 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 0 |
| lastAccessAt | 最后访问时间 | 最近一次被查看的时间 | 选填 | 日期 | 否 | 无 | 是 | 无 |
| lastDeliveryMarkAt | 最后投递标记时间 | 最近一次被标记投递的时间 | 选填 | 日期 | 否 | 无 | 是 | 无 |
| status | 发布状态 | published(发布)/draft(草稿) | 必填 | 下拉选项 | 否 | 无 | 是 (默认published) | 有 |
| createdAt | 创建时间 | 记录生成的具体时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 记录最后修改的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 2. 用户主表 (users)

- **核心用途**：存储 C 端用户的核心账号信息、登录凭证及分销邀请关系。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 用户唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 关联 Profile/Wallet 等 | 是 | 有 (演示账号) |
| phone | 手机号 | 登录用的手机号 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| passwordHash | 密码哈希 | 加密后的登录密码 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| myInviteCode | 个人邀请码 | 用于邀请他人的专属代码 | 必填 | 文本 | 是 (唯一键) | 无 | 是 | 有 |
| parentUid | 邀请人 ID | 谁邀请了该用户 | 选填 | 文本 | 否 | 关联本表 id (父子关系) | 否 | 无 |
| status | 账号状态 | active(活跃)/frozen(冻结) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| sourceType | 来源类型 | 注册来源（如 seed, invite） | 选填 | 文本 | 否 | 无 | 否 | 有 |
| createdAt | 注册时间 | 用户注册的具体时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| lastLoginAt | 最后登录时间 | 用户最近一次登录的时间 | 选填 | 日期 | 否 | 无 | 是 | 无 |

## 3. 用户资料详情表 (user_profiles)

- **核心用途**：存储用户的求职画像，如姓名、学历、学校等详细个人信息。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 资料唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| userId | 所属用户 ID | 关联的用户 ID | 必填 | 文本 | 是 (唯一键) | 关联 users.id | 否 | 有 |
| name | 真实姓名 | 用户填写的姓名 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| graduationYear | 毕业年份 | 用户毕业的年份 (如 2026) | 选填 | 数字 | 否 | 无 | 否 | 有 |
| degree | 最高学历 | 本科、硕士等 | 选填 | 下拉选项 | 否 | 无 | 否 | 有 |
| schoolName | 学校名称 | 毕业或就读学校 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| major | 所学专业 | 具体的专业名称 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| updatedAt | 最后更新时间 | 资料最后修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 4. 用户求职意向表 (user_job_preference_tags)

- **核心用途**：存储用户在“专属推荐”功能中设置的意向标签（城市、岗位、公司）。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 意向记录 ID | 自增数字 ID | 必填 | 数字 | 是 | 无 | 是 (自增) | 有 |
| userId | 所属用户 ID | 关联的用户 ID | 必填 | 文本 | 是 (唯一键) | 关联 users.id | 否 | 有 |
| intentionCity | 意向城市 | JSON 数组存储城市名 | 必填 | 文本(JSON) | 否 | 无 | 否 | 有 |
| intentionJob | 意向岗位 | JSON 数组存储岗位名 | 必填 | 文本(JSON) | 否 | 无 | 否 | 有 |
| intentionCompany | 意向公司 | JSON 数组存储公司名 | 必填 | 文本(JSON) | 否 | 无 | 否 | 有 |
| createTime | 创建时间 | 意向首次设置时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updateTime | 更新时间 | 意向最近修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 5. 求职进度追踪表 (user_job_tracking)

- **核心用途**：记录用户对特定招聘公告的标记行为及求职进度。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 追踪记录 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 无 |
| userId | 操作用户 ID | 关联的用户 ID | 必填 | 文本 | 否 | 关联 users.id | 否 | 无 |
| jobId | 对应岗位 ID | 关联的招聘公告 ID | 必填 | 文本 | 否 | 关联 job_announcements.id | 否 | 无 |
| progressStatus | 求职进度状态 | 已投递、面试中、已录用等 | 必填 | 下拉选项 | 否 | 无 | 否 | 无 |
| createdAt | 创建时间 | 首次标记时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 进度变更时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

*注：本表通过 [userId, jobId] 建立唯一约束，确保每个用户对同一岗位只有一条进度记录。*
