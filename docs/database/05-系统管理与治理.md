# 数据库表说明 - 系统管理与治理

本分类包含管理 Offer360 后台系统的相关数据表，包括管理员账号、角色、RBAC 权限体系以及全量操作审计日志。

## 1. 后台管理员表 (admin_users)

- **核心用途**：存储可以登录后台管理系统的运营人员账号信息。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 管理员唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 关联角色/日志表 | 是 | 有 (offer360_admin) |
| username | 登录账号 | 后台登录使用的用户名 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| passwordHash | 密码哈希 | 加密后的登录密码 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| realName | 真实姓名 | 备注显示的管理员名字 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| phone | 手机号 | 管理员联系方式 | 选填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| email | 邮箱 | 管理员电子邮箱 | 选填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| status | 账号状态 | active(正常), disabled(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| remark | 备注说明 | 对该账号用途的描述 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| lastLoginAt | 最后登录时间 | 管理员最近一次进入后台时间 | 选填 | 日期 | 否 | 无 | 是 | 无 |
| createdAt | 创建时间 | 账号开设时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最近资料修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 2. 后台角色表 (admin_roles)

- **核心用途**：定义后台的不同管理职位（如：超级管理员、运营、财务）。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 角色唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 (super-admin) |
| code | 角色代码 | 系统内部标识 (如 super-admin) | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| name | 角色名称 | 界面展示的职位名 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| description | 角色描述 | 该角色的具体权能简述 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| status | 状态 | active(启用), inactive(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| createdAt | 创建时间 | 角色创建时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 变更时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 3. 管理员-角色中间表 (admin_user_roles)

- **核心用途**：实现管理员与角色之间的多对多绑定（一名管理员可以拥有多个角色）。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 绑定 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| adminUserId | 管理员 ID | 关联的管理员 | 必填 | 文本 | 否 | 关联 admin_users.id | 否 | 有 |
| roleId | 角色 ID | 关联的角色 | 必填 | 文本 | 否 | 关联 admin_roles.id | 否 | 有 |
| createdAt | 绑定时间 | 权限赋予的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 4. 后台权限权限表 (admin_role_permissions)

- **核心用途**：存储各角色拥有的具体后台 API 操作权限码（如：用户管理、订单查看）。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 权限配置 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| roleId | 所属角色 | 哪个角色拥有此权限 | 必填 | 文本 | 否 | 关联 admin_roles.id | 否 | 有 |
| permissionKey | 权限唯一码 | 功能标识 (如 dashboard:view) | 必填 | 文本 | 否 | 无 | 否 | 有 |
| permissionName | 权限名称 | 易读的功能描述 (如 查看工作台)| 必填 | 文本 | 否 | 无 | 否 | 有 |
| permissionGroup| 权限分组 | 功能所属模块分组 (如 user) | 选填 | 文本 | 否 | 无 | 否 | 有 |
| permissionType | 权限类型 | 默认为 api 级别权限 | 必填 | 文本 | 否 | 无 | 是 (默认api) | 有 |

---

## 5. 管理员操作审计日志表 (admin_operation_logs)

- **核心用途**：记录管理员在后台进行的每一次增删改操作，用于安全回溯和责任追踪。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 日志 ID | 自增长 BigInt | 必填 | 数字 | 是 | 无 | 是 (自增) | 无 |
| adminUserId | 操作人 ID | 谁执行了操作 | 选填 | 文本 | 否 | 关联 admin_users.id | 是 (SetNull) | 无 |
| module | 模块名称 | 哪个业务模块 (如 jobs, user) | 必填 | 文本 | 否 | 无 | 否 | 无 |
| action | 动作类型 | 做了什么 (如 create, update) | 必填 | 文本 | 否 | 无 | 否 | 无 |
| targetType | 目标类型 | 操作的对象类型 (如 user_id) | 选填 | 文本 | 否 | 无 | 否 | 无 |
| targetId | 目标 ID | 具体操作的数据 ID | 选填 | 文本 | 否 | 无 | 否 | 无 |
| requestMethod | 请求方式 | GET, POST, PATCH 等 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| requestPath | 请求路径 | 访问的 API 路由 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| requestPayload | 请求参数 | 具体的输入 JSON 数据 | 选填 | 文本(JSON) | 否 | 无 | 否 | 无 |
| responseSummary| 响应摘要 | 接口返回的执行结果简述 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| ip | 操作 IP | 管理员发起请求时的 IP 地址 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| userAgent | 浏览器指纹 | 操作员的设备环境信息 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| createdAt | 操作时间 | 实际记录入库的时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
