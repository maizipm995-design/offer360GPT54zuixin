# 数据库表说明 - 会员权益体系

本分类包含管理 C 端用户会员身份、权限、权益展示内容以及会员兑换码闭环管理的相关数据表。

## 1. 用户会员身份表 (user_memberships)

- **核心用途**：记录用户的会员等级（标准、超级）及有效期。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 记录编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| userId | 用户 ID | 关联的用户 ID | 必填 | 文本 | 是 (唯一键) | 关联 users.id | 否 | 有 |
| memberLevel | 会员等级 | standard(标准), super(超级) | 必填 | 下拉选项 | 否 | 无 | 是 (默认standard) | 有 |
| startAt | 生效时间 | 会员身份起始日期 | 必填 | 日期 | 否 | 无 | 否 | 有 |
| endAt | 到期时间 | 会员身份截止日期 | 必填 | 日期 | 否 | 无 | 否 | 有 |
| remainingDays | 剩余天数 | 系统计算的有效剩余天数 | 必填 | 数字 | 否 | 无 | 是 | 有 |
| sourceType | 来源方式 | manual(手动), redeem(兑换码) | 必填 | 下拉选项 | 否 | 无 | 是 (默认manual) | 有 |
| sourceRemark | 来源备注 | 具体开通原因或批次说明 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| openedByAdminId| 操作管理员 | 若为人工开通，记录管理员ID | 选填 | 文本 | 否 | 关联 admin_users.id | 否 | 无 |
| createdAt | 创建时间 | 记录生成时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最近修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 内容 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| slug | 标识别名 | 页面调用唯一标识 (如 benefits) | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| title | 页面标题 | 权益介绍显示的标题 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| htmlContent | HTML 源码 | 具体的权益图文 HTML 内容 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| status | 发布状态 | published(发布), draft(草稿) | 必填 | 下拉选项 | 否 | 无 | 是 (默认published) | 有 |
| version | 版本号 | 内容更新的版本追踪 | 必填 | 数字 | 否 | 无 | 是 (默认1) | 1 |

| publishedByAdminId| 发布管理员 | 谁操作了发布 | 选填 | 文本 | 否 | 关联 admin_users.id | 否 | 无 |
| createdAt | 创建时间 | 初始录入时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最近修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

## 3. 会员角色表 (member_roles)

- **核心用途**：定义 C 端用户的固定等级角色（免费用户、标准会员、超级会员）。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 角色编号 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| code | 角色代码 | 系统内部标识 (如 STANDARD_MEMBER) | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| name | 角色名称 | 界面展示名称 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| description | 描述 | 该角色的详细功能说明 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| status | 状态 | active(激活), inactive(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| isSystem | 系统预置 | 是否为不可删除的系统内置角色 | 必填 | 下拉选项 | 否 | 无 | 是 (默认true) | 有 |
| sortOrder | 排序权重 | 在前端或后台显示的顺序 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 0 |
| createdAt | 创建时间 | 角色创建时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最近修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 权限配置 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |

## 5. 兑换码批次表 (membership_redeem_code_batches)

- **核心用途**：后台批量生成兑换码的任务批次管理。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 批次 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| batchNo | 批次号 | 人工可读的批次编号 (如 RC2026...) | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| memberLevel | 赋予等级 | 该批次兑换后的等级 (standard/super) | 必填 | 下拉选项 | 否 | 无 | 是 (默认standard) | 有 |
| cardType | 卡片类型 | 月卡、季卡、年卡等标识 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| grantDays | 赠送天数 | 兑换后增加的会员有效期天数 | 必填 | 数字 | 否 | 无 | 否 | 有 |
| quantity | 生成数量 | 该批次生成的总码数 | 必填 | 数字 | 否 | 无 | 否 | 有 |
| usedCount | 已使用数 | 当前已被用户兑换的数量 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 0 |
| status | 批次状态 | active(可用), disabled(禁用) | 必填 | 下拉选项 | 否 | 无 | 是 (默认active) | 有 |
| validFrom | 开始有效期 | 该批次码何时开始可兑换 | 选填 | 日期 | 否 | 无 | 否 | 有 |
| validUntil | 结束有效期 | 该批次码最晚兑换期限 | 选填 | 日期 | 否 | 无 | 否 | 有 |
| createdByAdminId| 创建人 ID | 操作的管理员 | 选填 | 文本 | 否 | 关联 admin_users.id | 否 | 有 |

## 6. 会员兑换码表 (membership_redeem_codes)

- **核心用途**：存储每一个具体的、可供用户输入的兑换码字符串及其状态。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 码记录 ID | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 有 |
| code | 兑换码内容 | 用户输入的唯一字符串 | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 |
| batchId | 所属批次 ID | 关联的批次信息 | 必填 | 文本 | 否 | 关联 redeem_code_batches.id | 否 | 有 |
| status | 码状态 | unused(未用), used(已用), invalid(失效) | 必填 | 下拉选项 | 否 | 无 | 是 (默认unused) | 有 |
| validUntil | 最终有效期 | 该码的失效时间 | 选填 | 日期 | 否 | 无 | 否 | 有 |
| usedByUserId | 兑换用户 ID | 哪个用户用了这个码 | 选填 | 文本 | 否 | 关联 users.id | 否 | 无 |

| codeId | 关联具体码 | 对应码 ID | 必填 | 文本 | 否 | 关联兑换码表 | 否 | 无 |
