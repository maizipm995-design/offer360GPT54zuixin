# 数据库表说明 - 付费服务与订单

本分类管理全站提供的求职增值服务（如简历精修、面试辅导）以及用户购买这些服务产生的交易订单。

## 1. 服务产品表 (service_products)

- **核心用途**：存储系统提供的所有付费求职服务产品详情。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 产品唯一编号 | UUID 字符串 | 必填 | 文本 | 是 | 关联订单表 | 是 | 有 (8款预置服务) |
| name | 产品名称 | 如“简历精修”、“面试辅导” | 必填 | 文本 | 否 | 无 | 否 | 有 |
| description | 产品描述 | 服务的具体内容和卖点介绍 | 必填 | 文本 | 否 | 无 | 否 | 有 |
| price | 当前售价 | 用户实际需要支付的金额 | 必填 | 数字(Decimal) | 否 | 无 | 否 | 有 |
| originalPrice | 原始价格 | 用于划线价展示，体现折扣 | 必填 | 数字(Decimal) | 否 | 无 | 否 | 有 |
| score | 评分 | 该服务的平均用户评分 (如 4.9) | 必填 | 数字(Decimal) | 否 | 无 | 否 | 有 |
| salesCount | 销量 | 累计成交的订单数量 | 必填 | 数字 | 否 | 无 | 是 (默认0) | 有 |
| isHot | 是否热门 | 是否在前端展示“热门”标签 | 必填 | 下拉选项 | 否 | 无 | 是 (默认false) | 有 |
| status | 上架状态 | true(上架), false(下架) | 必填 | 下拉选项 | 否 | 无 | 是 (默认true) | 有 |
| createdAt | 创建时间 | 记录生成时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 最后修改时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |

---

## 2. 服务订单表 (service_orders)

- **核心用途**：记录用户购买求职服务的交易凭证及支付状态。
- **字段列表与说明**：

| 字段名 | 业务含义 | 存储内容 | 必填/选填 | 数据类型 | 唯一主键 | 关联关系 | 自动生成 | 默认数据 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| id | 订单内码 | UUID 字符串 | 必填 | 文本 | 是 | 无 | 是 | 无 |
| orderNo | 业务订单号 | 对外展示的唯一单号 (如 SO-...) | 必填 | 文本 | 是 (唯一键) | 无 | 否 | 有 (演示订单) |
| userId | 下单用户 ID | 关联的用户 ID | 必填 | 文本 | 否 | 关联 users.id | 否 | 有 |
| productId | 购买产品 ID | 关联的产品 ID | 必填 | 文本 | 否 | 关联 service_products.id| 否 | 有 |
| amount | 订单金额 | 下单时的实际成交价 | 必填 | 数字(Decimal) | 否 | 无 | 否 | 有 |
| payStatus | 支付状态 | paid(已付), pending(待付), refund(已退)| 必填 | 下拉选项 | 否 | 无 | 是 (默认paid) | 有 |
| payTime | 支付时间 | 实际完成支付的时间点 | 选填 | 日期 | 否 | 无 | 否 | 有 |
| refundReason | 退款原因 | 若发生退款，记录原因描述 | 选填 | 文本 | 否 | 无 | 否 | 无 |
| refundAt | 退款时间 | 实际退款的时间点 | 选填 | 日期 | 否 | 无 | 否 | 无 |
| remark | 订单备注 | 用户下单时的特殊要求或系统备注 | 选填 | 文本 | 否 | 无 | 否 | 有 |
| createdAt | 创建时间 | 订单生成时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
| updatedAt | 更新时间 | 状态变更时间 | 必填 | 日期 | 否 | 无 | 是 | 无 |
